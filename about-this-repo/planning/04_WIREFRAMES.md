## Library Screen

Use the available tablet width intentionally. Decide grid/list density and inspect real item states before accepting a design. Include pending/unavailable archive states without implying media was retrieved.

## Capture Screen

A clear URL input and feedback are required. Never put the server API token in a browser form; use future authenticated app-internal mutations.
